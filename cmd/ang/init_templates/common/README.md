## Preflight (n00b-friendly)

`make doctor` (or `task doctor`) runs `scripts/preflight.sh` and does:
- ensures `.env` exists (creates from `.env.example`)
- auto-fills missing env keys from `.env.example`
- runs `ang doctor start` (tools/env/compose/ports checks)
