## Preflight (n00b-friendly)

- `make bootstrap` (or `task bootstrap`) attempts to install missing tools on Ubuntu/macOS.
- `make doctor` (or `task doctor`) runs preflight + `ang doctor start` checks.
- scripts print consistent status output (`[ OK ]`, `[WARN]`, `[FAIL]`) with concrete fixes.

`make doctor` verifies:
- required tools (`ang`, `go`, `docker`, `docker compose`, `atlas`)
- `.env` bootstrap from `.env.example` and env autofill
- startup diagnostics from `ang doctor start`
